Import blog posts

Write one here instead {% if CAN('blog_list') %} Posts from Word{% endif %}

Write the post in Word like any other document, upload it here, and it becomes a draft you check and publish. An imported post is an ordinary post: open it in the editor to change anything, or replace it with a newer Word file from its settings.

  1. 1 Download the template

    A Word file with the Post details box (title, summary, cover, thumbnail, category and tags, what Google shows) and an example post showing every block, to type over.

    Blog template (.docx)
  2. 2 Write it like any Word document

    Headings, bold, lists and links as usual. Start a line with Tip:, Quote:, Button:, Video: or Slideshow: for the special blocks; type --- for a line. How each thing comes out

  3. 3 Paste the pictures in

    Right where they belong. The one at the top is the cover (1200 × 630); the thumbnail for the blog list is 800 × 450. A table of two cells puts a picture beside your words. Right-click → Edit Alt Text to describe a picture. Picture tips

  4. 4 Upload it here

    One document or several at once. Each becomes a draft — nothing is published until you say so.
