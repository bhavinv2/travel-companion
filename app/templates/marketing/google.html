How to connect them (about ten minutes, once)

Do these signed in with a Google account that owns the Analytics property and the Search Console property (for example the one that verified the site).

  1. Make the key. In Google Cloud, pick or make a project. APIs & Services › Library: switch on the Google Analytics Data API and the Google Search Console API. Then IAM & Admin › Service accounts › Create service account (no roles needed) › open it › Keys › Add key › Create new key › JSON. A file downloads. Its e-mail ends in iam.gserviceaccount.com.
  2. Let it read Analytics. In Google Analytics: Admin › Property access management › + › Add users › the service account's e-mail › role Viewer. Then Admin › Property details: copy the property id (a number like 412345678).
  3. Let it read Search Console. In Search Console, pick the site › Settings › Users and permissions › Add user › the same e-mail › permission Restricted. The property's name is at the top left: sc-domain:nriparentservice.com for a domain property, or https://nriparentservice.com/ for a URL-prefix one.
  4. Paste them below, press Save, then Test the connection.
