How to connect it (about five minutes, once)

  1. In Google Cloud, pick or make a project and switch on the Google Analytics Data API (APIs & Services › Library).
  2. IAM & Admin › Service accounts › Create. No roles are needed. Open it › Keys › Add key › JSON: a file downloads.
  3. In Google Analytics: Admin › Property access management › + › add the service account's e-mail (it ends in iam.gserviceaccount.com) as a Viewer.
  4. Admin › Property details: copy the property id (a number like 412345678).
  5. Paste both below and press Save, then Test the connection.
