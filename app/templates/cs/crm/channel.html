Where to find each one

  1. Phone number ID and WhatsApp Business Account ID: WhatsApp Manager › Phone numbers (the ids are under the number and the account name). Several accounts can list the same number: use the one where it shows Connected, not a Pending copy (your app's API Setup page may show a copy).
  2. Access token: Business Settings › Users › System users › the system user our WhatsApp CRM uses › Assign assets › WhatsApp accounts › this account, Full control. Then Generate new token for the same app, with whatsapp_business_messaging and whatsapp_business_management, never expiring.
  3. App secret: developers.facebook.com › that same app › App settings › Basic › App secret.
  4. Save, press Check with Meta, then Connect: Meta then sends this number's messages here, and the WhatsApp CRM's own number is untouched.
